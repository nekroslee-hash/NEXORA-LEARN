# پروژه NEXORA LEARN

یک نمونه وب‌سایت آموزشی فارسی و واکنش‌گرا برای تمرین HTML، CSS و JavaScript.

## اجرای پروژه
1. فایل ZIP را از حالت فشرده خارج کنید.
2. پوشه NEXORA-LEARN را با VS Code باز کنید.
3. فایل index.html را با مرورگر باز کنید.
4. برای تغییر ظاهر، style.css و برای تغییر رفتارها، script.js را ویرایش کنید.

## ساختار فایل‌ها
- index.html — ساختار و محتوای صفحه
- style.css — رنگ‌ها، چیدمان و طراحی واکنش‌گرا
- script.js — جست‌وجوی دوره‌ها، فیلترها، پنجره جزئیات و منوی موبایل

## امکانات
- طراحی فارسی راست‌چین (RTL)
- نمایش مناسب در موبایل و دسکتاپ
- جست‌وجو و فیلتر دوره‌ها
- نمایش سرفصل‌های هر دوره
- منوی موبایل
- بدون نیاز به نصب کتابخانه یا فریم‌ورک

## نکته مهم
فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ برای نمایش فونت در حالت آفلاین باید فونت را دانلود و به پروژه اضافه کنید. این پروژه فقط نمونه فرانت‌اند است و هنوز سامانه ثبت‌نام، پایگاه داده یا پنل مدیریت ندارد.
